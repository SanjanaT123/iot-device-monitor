# Spring Boot REST API Project

## Overview

This project is a backend application developed using Java and Spring Boot. It demonstrates RESTful API development, database connectivity using PostgreSQL, and CRUD operations following a layered architecture. The project showcases backend development concepts commonly used in enterprise applications.

## Features

- RESTful API development
- CRUD operations
- Spring Boot backend
- PostgreSQL database integration
- Layered architecture
- Maven project structure
- Exception handling
- Data persistence using JPA/Hibernate

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- REST APIs

## Installation

### Clone the repository

```bash
git clone https://github.com/SanjanaT123/Spring-Project.git
```

### Open the project

Import the project into IntelliJ IDEA, Eclipse, or VS Code.

### Configure PostgreSQL

Create a PostgreSQL database and update the database credentials in the `application.properties` file.

### Run the application

Run the Spring Boot application.

### Test the APIs

Use Postman or any REST client to test the available API endpoints.
